# Asset notes

The SVGs in this folder are drawn by script. No raster images are used.

## Type

The nameplate and band captions (AI ENGINEER, BUILD, REMEMBER, SHIP, TRUST, shelf counts, map header) are glyph outlines, not live text. They come from Barlow Condensed ExtraBold, copyright 2017 The Barlow Project Authors, licensed under the SIL Open Font License 1.1 (https://openfontlicense.org). Only the outlines ship here. The font file does not.

Shelf names, folder names, and legend text are live text in the system sans stack, so they stay selectable and readable by screen readers.
