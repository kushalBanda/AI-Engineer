# LLMOps and cloud

[← AI Engineer](../README.md)

Ship models and AI apps. This shelf covers CI/CD, containers, Kubernetes, and cloud deploys, from a toy Lambda to a monitored RAG service.

## Modules

| Module | What you'll build | Tier | Stack |
| :--- | :--- | :--- | :--- |
| [`aws-ec2-fastapi/`](aws-ec2-fastapi/) | A FastAPI bookstore on an EC2 instance | Beginner | AWS EC2, FastAPI |
| [`lambda-github-actions/`](lambda-github-actions/) | A Lambda function that redeploys on every push to `main` | Beginner | AWS Lambda, GitHub Actions |
| [`github-actions/`](github-actions/) | An ML pipeline: train, serve with Flask, containerize, deploy to GKE | Intermediate | GitHub Actions, Docker, GKE, scikit-learn |
| [`kubernetes/`](kubernetes/) | A RAG API on Kubernetes with Prometheus monitoring | Advanced | FastAPI, Docker, Kubernetes, Prometheus |
| [`tools/`](tools/) | A checklist of MLOps tools to learn next | Reference | GCP, GitLab, CircleCI, Jenkins, Argo, MLflow |

## Reading order

1. `aws-ec2-fastapi/`: deploy by hand once.
2. `lambda-github-actions/`: automate a tiny deploy.
3. `github-actions/`: automate a full ML pipeline.
4. `kubernetes/`: run and monitor a service at scale.
