# Agentic systems

[← AI Engineer](../README.md)

Agents that plan, call tools, and hand work to each other. This shelf builds the same ideas in three stacks, so you can compare how each one models state, tools, and control flow.

## Modules

| Module | What you'll build | Tier | Stack |
| :--- | :--- | :--- | :--- |
| [`langgraph/`](langgraph/) | Chatbots, ReAct agents, RAG, memory, a drafting agent, prompt chaining, parallel workflows, subgraphs | Beginner to advanced | LangGraph, LangChain |
| [`openai-agents/`](openai-agents/) | A simple agent, guardrails, a manager agent, router and triage patterns | Intermediate | OpenAI Agents SDK (Python) |
| [`agent-sdk-ts/`](agent-sdk-ts/) | Hello world, agent-as-tool, dynamic instructions | Beginner | OpenAI Agents SDK (TypeScript) |

## Reading order

1. `langgraph/`: start with `Basics/`, then `Agent/`, then `Workflows + Agents/`.
2. `openai-agents/`: compare the SDK's agent loop with LangGraph's explicit graph.
3. `agent-sdk-ts/`: see the same SDK in TypeScript.
