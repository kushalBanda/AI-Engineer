# Security policy

## Report a problem

Use GitHub private vulnerability reporting. Do not open a public issue.

1. Open the [Security tab](https://github.com/kushalBanda/AI-Engineer/security/advisories/new).
2. Select **Report a vulnerability**.
3. Describe the problem, the file path, and the steps to see it.

You will get a reply within seven days.

## What to report

- A leaked API key, token, password, or service account file.
- Code in a module that exposes user data or runs untrusted input.
- A dependency with a known vulnerability.

## If you find a leaked secret

1. Do not use the secret.
2. Report it with the steps above.
3. If the secret is yours, revoke it at the provider first.

## Scope

This repo holds learning modules. Treat them as examples, not production code. Review any module before you run it with real data or real keys.
